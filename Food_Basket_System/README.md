# 🌿 نظام السلة الغذائية الأردنية

مبني على منهجية منظمة الأغذية العالمية (FAO/WHO) — Enhance Platform

---

## 🚀 تشغيل النظام
```bash
python setup_and_run.py

```

---

## 📁 هيكل المشروع

```
food_basket/
├── app.py                  ← خادم Flask الرئيسي
├── nutrition_engine.py     ← محرك الحسابات الغذائية
├── setup_and_run.py        ← سكريبت التثبيت والتشغيل
├── requirements.txt        ← قائمة المكتبات
├── database/
│   ├── init_db.py          ← تهيئة وبذر قاعدة البيانات
│   └── nutrition.db        ← SQLite (يُنشأ تلقائياً)
├── templates/
│   └── index.html          ← واجهة المستخدم
└── uploads/                ← ملفات الأسعار المرفوعة
```

---

## 📋 كيفية الاستخدام

1. **رفع ملف الأسعار** — حمّل النموذج أولاً ثم أضف الأسعار
2. **إدخال بيانات الأفراد** — العمر، الجنس، الوزن، الطول، النشاط البدني
3. **تحديد مدة السلة** — أسبوع/شهر/ربع سنة
4. **عرض النتائج** — السلة المثلى بأقل تكلفة مع تغطية كاملة

---

## 🧮 المعادلات العلمية

- **BMR**: معادلة Schofield (WHO/FAO)
- **TDEE**: BMR × PAL
- **التحسين**: Linear Programming (PuLP/CBC)

---

## 🗄️ قواعد البيانات

| الجدول | المحتوى |
|--------|---------|
| `nutritional_requirements` | متطلبات المغذيات حسب العمر والجنس |
| `food_groups` | مجموعات الأغذية ونسب الطاقة |
| `food_composition` | تركيبة 25+ غذاء أردني لكل 100غ |
| `special_requirements` | احتياجات الحوامل والمرضعات والرضع |
| `pal_values` | معاملات النشاط البدني |
